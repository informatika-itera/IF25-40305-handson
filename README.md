# Hands-on IF25-40305: Sistem Terdistribusi dan Multimedia
## 📦 Arsip Semester Ganjil 2025/2026 (2025_1)

Branch ini berisi arsip modul, notebook hands-on, skrip, dan dataset praktikum untuk mata kuliah **IF25-40305 Sistem Terdistribusi dan Multimedia (STM)** pada **Semester Ganjil 2025/2026** di Program Studi Teknik Informatika, Institut Teknologi Sumatera (ITERA).

---

### 📂 Daftar Materi:
1. **Audio Processing**:
   - `1_Module_Audio.ipynb`
   - `file_suara/`: Sampel audio praktikum
   - `output/` & `outputaudio/`: Hasil filter, fade, dan normalisasi audio
2. **Image Processing**:
   - `2_working_with_image.ipynb`
   - `data/`: Dataset citra pengujian
3. **Face, Pose & Landmark Detection**:
   - `3_face_detection.ipynb` & `3_face_recog_lecture.py`
   - `3_facial_landmark.ipynb`
   - `3_pose_landmark.ipynb`
   - `3_tracking_wajah.py` & `3_tracking_wajah2.py`
   - `hand_drawing_app.py` & `klt_drawing_app.py`
4. **Interactive Visualizations**:
   - `react-visualizations/`: Komponen web visualisasi ADC dan piksel
