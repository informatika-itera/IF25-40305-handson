> **Tip:** Anda dapat berpindah ke materi semester lampau kapan saja melalui dropdown **Branch** di GitHub atau menggunakan perintah git di terminal:
> ```bash
> git switch <nama_branch>
> # Contoh: git switch 2025_2
> ```

## 💻 Panduan Clone untuk Mahasiswa

Untuk mengunduh materi semester aktif saat ini:

```bash
git clone https://github.com/informatika-itera/IF25-40305-handson.git
cd IF25-40305-handson
```

Jika koneksi internet terbatas, gunakan *shallow clone* untuk proses unduh yang lebih cepat:
```bash
git clone --depth 1 https://github.com/informatika-itera/IF25-40305-handson.git
```

## ❗ Peraturan & Integritas Hands-on

1. **Anti-Plagiarisme & Joki**: Dilarang keras menggunakan jasa joki atau menyalin kode mahasiswa lain baik dalam pengerjaan tugas mingguan maupun ujian.
2. **Atribusi Kolaborasi**: Jika berdiskusi atau mendapat bantuan dari rekan, cantumkan Nama dan NIM rekan tersebut secara transparan di dalam notebook.
3. **Pemanfaatan AI**: Penggunaan asisten AI (ChatGPT, Claude, Gemini, dll.) diperbolehkan sebagai sarana belajar, namun wajib mencantumkan prompt, penjelasan, dan konteks chat di dalam laporan/notebook.
4. **Sanksi**: Pelanggaran terhadap integritas akademik akan diproses sesuai peraturan yang berlaku di ITERA.
